# 原作 STED2 の文書

STED2 のソース公開（1998 年 5 月、ゆいＮＥＴ）に添えられた文書です。公開時の条件「公開時には必ず、付属の DOC & HIS等を添付してください」に敬意を表して、原文のまま添付しています。

| ファイル | 内容 |
|---|---|
| `追悼.DOC` | ソース公開にあたっての追悼の言葉と、転載・改変の条件（原文、Shift_JIS・CRLF） |
| `STED207M.HIS` | STED2 の版ごとの変更履歴（原文、Shift_JIS・CRLF） |
| `*.utf8.txt` | 上の 2 つを UTF-8・LF に変換した読み物版（内容は同じ） |
